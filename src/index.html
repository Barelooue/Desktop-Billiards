    球局、计时与存档

    中八清完选定的一组球后，合法打进黑八即可获胜；黑八提前落袋或犯规落袋判负。斯诺克红球 1 分，黄、绿、棕、蓝、粉、黑分别为 2—7 分；红彩交替、彩球复位，最后按分值清彩，全部目标球清完即结束。最后黑球阶段犯规时，单人清台挑战判负。人机对战先给对手加分，再按比分判胜负，同分复位黑球。犯规罚分按规则应计给对手，单人练习单独记录，人机对战计入对手得分。

    秒表统计实际游戏时间，暂停、后台和退出期间不计时。Esc 退出或返回主页会保存未完成的球局，可在“历史球局”继续；胜负已定则删除该局存档。继续时取消未出手的蓄力并回到观察视角，球的位置、运动、得分和用时保留。

    开始与姿态

    先选择玩法，再开始球局、确认母球摆位，起身绕台选站位，最后俯身击球。只有姿态过渡完成后才能出杆。俯身锁定站位，球杆围绕母球击打位置左右各转 90°，合计半圈；超出这一半圈时先起身换站位。成功出杆后立即自动起身并平滑回到台边站立观察位置，不等球停。起身时如同站在台边、佩戴头部相机观察，保持正常眼高和稳定焦距，近处的球更清晰。画面允许只显示部分球台，通过沿四边和圆角走动查看各处；镜头朝向球台中心，不跟随母球，桌面与球桌保持不动。

    鼠标操作

    也可左右移动鼠标调杆，横移一个画面宽度对应半圈；按住精细调节键可慢速微调。左键按住向下拉杆、松开出杆，拉回起点取消。起身后右键拖动绕台，滚轮调观察高度。观察和俯身时都可点击或拖动母球剖面选击打点；摆位时立即切换到台边站立观察视角，可用绕台快捷键或右键拖动换角度、滚轮调观察高度，再在台面或摆位图中点击、拖动母球。

    巧粉与加塞

    桌边放有蓝色巧粉，可直接点击，也可点击“擦巧粉”按钮。出杆按力度和加塞消耗皮头抓球状态；不足时实际发力和旋转减弱。自动擦粉并放回原位后恢复，擦粉期间不能出杆或绕台；暂停会暂停动作，中途退出不提前恢复，续局保留原抓球状态。击打点上方为高杆、下方为低杆，左右为侧旋，击打点最多偏离球心约 0.75 倍球半径。每杆结束自动归中。

    玩法与摆球权

    开球时九球 / 中八母球在开球线后，斯诺克在 D 区。获得摆球权后，可反复调整，再确认位置；不能与球库、袋口或其他球重叠。普通击球间不能任意移动球。

    Esc 统一返回上一级，不能改键：设置返回球台，历史球局和结算弹窗返回主页，对局保存并返回主页，主页关闭程序。也可使用设置快捷键或“返回球台”按钮关闭设置；点击按键栏之外可离开改键。不支持 Ctrl / Alt / Win 组合键；Tab 和部分系统功能键保留。切换窗口、打开设置或起身会取消未完成的蓄力。
    当前为单人练习模拟：包含滑动 / 滚动摩擦、旋转、球间摩擦、库边反弹和袋口碰撞。参数未经实测标定；不模拟跳球、扎杆、杆身偏移及完整赛事裁判。引导线仅预测首次接触。画质使用原生分辨率和高精度光影。
